• Ctrl (Control) + H ― Help
  • Ctrl (Control) + Num (1-9) ― open I-th task
  • Ctrl (Control) + U ― go up to parent
  • Ctrl (Control) + G ― open Navigate window
  • Ctrl (Control) + R ― Resolve task, question, problem
  • = ― New task
  • Ctrl (Control) + O ― New subtask for selected task
  • Ctrl Alt (Meta) + O ― New Task and Focus it
  • Ctrl (Control) + Y ― New Task and Go to it
  • Ctrl (Control) + Alt (Meta) + Y ― New Task for focused task and Go to it
  • Ctrl (Control) + P ― New Problem
  • Ctrl (Control) + Q ― New Question
  • Ctrl (Control) + H ― Help
  • Ctrl (Control) + T ― Finish all tasks inside (and stay here)
  • Ctrl (Control) + M ― Notes
  • \ ― Anonymous task
  • Ctrl (Control) + S ― Select Subtask for focus
